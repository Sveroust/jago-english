# KURIKULUM & MODUL MATERI JAGO ENGLISH (CEFR A1 - C2)
**Blueprint Penguasaan Bahasa Inggris Berbasis First-Principles Linguistics & Cognitive Recall**

> [!IMPORTANT]
> **Akar Masalah Pembelajar Indonesia (Contrastive Linguistics):**
> Otak penutur Bahasa Indonesia terbiasa dengan bahasa **tanpa konjugasi waktu pada kata kerja** (*Saya makan kemarin / sekarang / besok*), **tanpa kopula wajib sebelum kata sifat** (*Dia sibuk* vs *She is busy*), dan **urutan Diterangkan-Menerangkan** (*Mobil merah besar* vs *Big red car*). Metode **Jago English** membedah jembatan logika antara struktur Bahasa Indonesia dan Bahasa Inggris agar Anda berpikir langsung dalam pola kalimat Inggris tanpa menerjemahkan kata demi kata di kepala.

## 2. Bedah First-Principles: 3 Hukum Inti Bahasa Inggris

### Hukum 1: Setiap Kalimat Bahasa Inggris Wajib Punya "Mesin Penggerak" (Verb atau Copula Be)
Dalam Bahasa Indonesia, kita bisa berkata:
- *Saya lapar.* (Tanpa kata kerja)
- *Kantor itu di Jakarta.* (Tanpa kata kerja)

Dalam Bahasa Inggris, kalimat **haram berdiri tanpa kata kerja**. Jika tidak ada aksi fisik/mental (*run, eat, think, analyze*), maka wajib dipasang **Copula `Be` (`am / is / are / was / were`)** sebagai penyambung subjek dan predikat:
- **Ada Aksi (Action Verb):** `I work at the headquarters.` -> Negatif/Tanya meminjam `do/does/did`: `I do not work.`
- **Tidak Ada Aksi (Nominal / State):** `I am hungry.` / `The office is in Jakarta.` -> Negatif/Tanya langsung membalik `be`: `Is the office in Jakarta?`

### Hukum 2: Matriks 12 Tenses sebagai Koordinat Ruang-Waktu (Time x Aspect)
Seluruh tenses Bahasa Inggris hanyalah perkalian antara **3 Waktu (Time)** dan **4 Sudut Pandang (Aspect)**:

| Sudut Pandang (Aspect) | Makna Logis (Mental Model) | Present (Sekarang/Fakta) | Past (Masa Lampau) | Future (Masa Depan) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Simple** *(Titik Fakta / Kebiasaan)* | Fakta utuh atau jadwal tetap | **Present Simple** `S + V1(s/es)` *I write code every day.* | **Past Simple** `S + V2` *I wrote code yesterday.* | **Future Simple** `S + will + V1` *I will write code tomorrow.* |
| **2. Continuous** *(Sedang Berlangsung)* | Proses yang sedang aktif di tengah jalan (`Be + V-ing`) | **Present Continuous** `am/is/are + V-ing` *I am writing code now.* | **Past Continuous** `was/were + V-ing` *I was writing code at 8 PM.* | **Future Continuous** `will be + V-ing` *I will be writing code at 8 PM.* |
| **3. Perfect** *(Sudah Selesai / Berdampak)* | Aksi yang sudah tuntas sebelum titik waktu acuan (`Have + V3`) | **Present Perfect** `have/has + V3` *I have written the report.* | **Past Perfect** `had + V3` *I had written it before he called.* | **Future Perfect** `will have + V3` *I will have written it by Friday.* |
| **4. Perfect Continuous** *(Durasi Berkelanjutan)* | Sudah mulai di masa lalu dan masih berlanjut hingga titik acuan (`Have been + V-ing`) | **Present Perf. Cont.** `have/has been + V-ing` *I have been writing for 3 hours.* | **Past Perf. Cont.** `had been + V-ing` *I had been writing for 2 hours when it rained.* | **Future Perf. Cont.** `will have been + V-ing` *I will have been writing for 5 hours by noon.* |

### Hukum 3: Dimensi Preposisi Ruang & Waktu (`AT` -> `ON` -> `IN`)
- **`AT` (Titik Spesifik / 0D):** `at 07:30 AM`, `at midnight`, `at the entrance`, `at 221B Baker Street`.
- **`ON` (Permukaan / Garis 1D-2D):** `on Monday`, `on November 9th`, `on the table`, `on the second floor`, `on the website`.
- **`IN` (Ruang Tertutup / Volume 3D / Rentang Panjang):** `in November`, `in 2026`, `in Jakarta`, `in the contract`.
